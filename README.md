# Les Cubes Magiques

Petit jeu parlant pour apprendre l'alphabet, les syllabes, la lecture, les chiffres et à compter, pensé pour un enfant de 4 ans.

**Jouer :** https://tonychev.github.io/cubes-magiques/

- L'alphabet (des mots différents à chaque fois), Trouve la lettre, Les syllabes, Lire des mots, Les chiffres, Compter, Memory
- Voix française (synthèse vocale du navigateur), étoiles et autocollants à gagner
- Espace parents : maintenir appuyé 2 secondes sur ⚙️ en bas de l'accueil

Un seul fichier `index.html`, sans dépendance ni compilation.
